# ⚡ elementista.github.io

> [ MINHA MATRIX. MEU MUNDO. MINHAS REGRAS. SEU ESPAÇO. ]

Portal técnico independente e diário de bancada oficial do **Elementista**. Um espaço limpo, feito à mão e livre de automações terceirizadas ou frameworks proprietários comerciais.

---

## 🖥️ Estrutura do Ecossistema
* **index.html:** Linha do tempo centralizada com dossiês técnicos e artigos cronológicos.
* **projetos.html:** Vitrine de utilitários portáteis (Elementista Browser, Flash Vault e Verificador de Hardware).
* **sobre.html:** Perfil do operador, linhas de atuação em engenharia de sistemas e filosofia.

---

## 🛠️ Engenharia Invisível Aplicada
* **Fundo Matrix Autônomo:** Script vanilla em JavaScript (`js/matrix.js`) que injeta e gerencia o elemento canvas diretamente na memória do DOM, blindando o layout físico.
* **Leitor de Artigos Dinâmico:** Integração via `iframe` elástico (`js/leitor.js`) responsivo com suporte mobile (vh/vw), permitindo a leitura de postagens externas completas sem tirar o usuário do domínio principal.
* **Folha de Estilo Pura:** Interface responsiva customizada em CSS puro (`css/estilo.css`), adaptada para modo escuro de alta legibilidade, com fontes monoespaçadas estilo terminal.
